# 취향 해부실 · Character Taste Analyzer

좋아하는 캐릭터를 모아 취향 분석용 ChatGPT 프롬프트를 만들어 주는 정적 웹페이지입니다.

## 기능

- 최대 10명의 작품명·캐릭터명·메모 입력
- 이미지 파일 선택 또는 클립보드 이미지 붙여넣기
- AI 분석 프롬프트 생성 및 복사
- API 키·서버 없이 동작하며, 입력 내용과 이미지는 브라우저 밖으로 전송하지 않음

## GitHub Pages 배포

GitHub 저장소 **Settings → Pages**에서 `Deploy from a branch`를 선택하고, `main` 브랜치의 `/(root)`를 지정하면 됩니다.
